Portfolio admin

Upload, organise, edit and delete the photos on your portfolio site. Changes are saved straight to your GitHub repository.

How do I get a token?
  1. Open GitHub, then Settings, Developer settings, Fine-grained tokens, Generate new token.
  2. Under Repository access, choose only your portfolio repository.
  3. Under Permissions, set Contents to Read and write.
  4. Generate the token, copy it and paste it above.

The token stays in this browser and is only sent to api.github.com. Never save it inside the repository.
